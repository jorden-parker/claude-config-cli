# Context diet: settings and env vars that cut Claude Code context and tokens

- Date: 2026-10-16
- Scope: recommendations for ccfg's "context diet" checklist. Each row names a settings key or env var, checks whether it is applied, and says how to apply it.
- Catalogue: `internal/schema/schema.json` (generatedOn 2026-10-16). Settings entries carry type/default/options. Env var entries carry only name and purpose text, so their types and defaults below come from the docs, not the catalogue.
- Settings file locations: user `~/.claude/settings.json`; project `.claude/settings.json`; local `.claude/settings.local.json`. `~/.claude.json` is a separate global file (not a settings file).
- Anchors are taken from heading text. If an anchor does not resolve, use the page URL.

## Changes since the 2026-10-07 doc

I cannot diff against the old page versions (only the old doc's text is available). This compares the old doc's claims with the live docs.

**Confirmed (unchanged):**

- `/effort` saves per model in `modelSettings`. A top-level user `effortLevel` no longer applies to Opus 5.5 and later. [model-config](https://code.claude.com/docs/en/model-config#adjust-effort-level), [settings-reference](https://code.claude.com/docs/en/settings-reference#effortlevel)
- `alwaysThinkingEnabled` and `MAX_THINKING_TOKENS=0` do nothing on Opus 5.5, Sonnet 5.5, Haiku 5.5 and Fable. [settings-reference](https://code.claude.com/docs/en/settings-reference#alwaysthinkingenabled), [env-vars](https://code.claude.com/docs/en/env-vars)
- MCP tool search defers by default. `auto` is a 10% threshold and `auto:N` sets another percentage. [mcp](https://code.claude.com/docs/en/mcp#configure-tool-search)
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` is not a token setting. [env-vars](https://code.claude.com/docs/en/env-vars)
- `promptCacheTtl` and `subagentPromptCacheTtl` need v2.1.242+. [prompt-caching](https://code.claude.com/docs/en/prompt-caching#choose-the-ttl-yourself)
- Auto memory loads the first 200 lines or 25KB of `MEMORY.md`. [memory](https://code.claude.com/docs/en/memory)

**Corrected or narrowed:**

- `alwaysLoad: true` in `.mcp.json` does more than the old doc said. It also makes startup wait for that server's tools, up to the 5-second connect timeout. [mcp](https://code.claude.com/docs/en/mcp#exempt-a-server-from-deferral)
- Prompt suggestions are on by default (`promptSuggestionEnabled` default `true`). They are off by default only in sessions that do not fetch feature flags. The env var `CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false` overrides the setting. [settings-reference](https://code.claude.com/docs/en/settings-reference#promptsuggestionenabled), [interactive-mode](https://code.claude.com/docs/en/interactive-mode#when-claude-code-skips-suggestions)
- `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` also turns off MCP tool search, so MCP definitions load upfront. [env-vars](https://code.claude.com/docs/en/env-vars), [mcp](https://code.claude.com/docs/en/mcp#configure-tool-search)

**Not confirmed:**

- The old doc says `disable-model-invocation: true` removes a skill's description from automatic context. The fetched skills text says it stops automatic loading and preloading into subagents. It does not say the description is removed from the listing. Marked unverified in the table.

**New in the live docs (not in the old doc):**

- Skill listing budget: `skillListingBudgetFraction` (default 0.01) and `skillListingMaxDescChars` (default 1536). [settings-reference](https://code.claude.com/docs/en/settings-reference#skilllistingbudgetfraction)
- `/skill-doctor` (v2.1.252+) shows per-skill cost. [skills](https://code.claude.com/docs/en/skills)
- `autoCompactWindow`, `idleCompaction` (on by default), `CLAUDE_CODE_AUTO_COMPACT_WINDOW`. [settings-reference](https://code.claude.com/docs/en/settings-reference#autocompactwindow)
- `bashOutputMaxChars` (default 30,000 inline, clamped 4000-128000). [settings-reference](https://code.claude.com/docs/en/settings-reference#bashoutputmaxchars)
- `claudeMdExcludes` for monorepos. [settings-reference](https://code.claude.com/docs/en/settings-reference#claudemdexcludes)
- Per-tool `anthropic/alwaysLoad` set by MCP server authors, and `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`. [mcp](https://code.claude.com/docs/en/mcp#per-tool-alwaysload)
- `/usage` prompt-cache line (v2.1.251+). [costs](https://code.claude.com/docs/en/costs#prompt-cache-statistics)

## Not detectable from settings files (informational rows)

Keep these in the checklist as reminders. ccfg cannot confirm them from settings files.

- **`/clear` between unrelated tasks.** Stale context is billed on every later message. Session state is not in settings. [costs](https://code.claude.com/docs/en/costs#manage-context-proactively)
- **`/compact` with focus text, and a `# Compact instructions` section in CLAUDE.md.** Compaction is itself a large request. Run it at natural breaks. [costs](https://code.claude.com/docs/en/costs#manage-context-proactively) ; [prompt-caching](https://code.claude.com/docs/en/prompt-caching#compacting-the-conversation)
- **`/context` to find the largest category.** Shows what loads. Run it in a live session. [costs](https://code.claude.com/docs/en/costs#reduce-mcp-server-overhead)
- **`/usage` for session totals, cache hit ratio and plan attribution.** Live numbers, not stored in files. [costs](https://code.claude.com/docs/en/costs#using-the-usage-command)
- **`/skill-doctor` and `/insights`.** Reports on skill cost and usage habits, written to `~/.claude/usage-data/`. [skills](https://code.claude.com/docs/en/skills) ; [costs](https://code.claude.com/docs/en/costs#analyze-your-usage-patterns)
- **Trimming the content of CLAUDE.md.** Line count is checkable (row `claude-md-under-200-lines`). Whether the content is useful is not. [memory](https://code.claude.com/docs/en/memory#my-claudemd-is-too-large)
- **Keeping `MEMORY.md` short.** Only the first 200 lines or 25KB load. Check the line count of `~/.claude/projects/<project>/memory/MEMORY.md` by hand. [memory](https://code.claude.com/docs/en/memory#auto-memory)
- **Plan mode, specific prompts, verification targets.** Behavior, not configuration. [costs](https://code.claude.com/docs/en/costs#work-efficiently-on-complex-tasks)
- **Small agent teams and shut down idle teammates.** Each teammate keeps its own context. [costs](https://code.claude.com/docs/en/costs#agent-team-token-costs)
- **Hook scripts that filter verbose output before Claude sees it.** The hook config is in settings, but the filter logic is in a script. Check `hooks` in settings and the script by hand. [costs](https://code.claude.com/docs/en/costs#offload-processing-to-hooks-and-skills) ; [hooks](https://code.claude.com/docs/en/hooks)
- **Scheduled tasks and `/loop` left running on an idle session.** Each run sends the full context. [costs](https://code.claude.com/docs/en/costs#why-usage-climbs-in-a-long-session)
- **Leaving a session idle for a long time.** Idle compaction (`idleCompaction`, on by default) can shorten it, and the cache expires. Behavior, not a setting to check. [prompt-caching](https://code.claude.com/docs/en/prompt-caching#compacting-the-conversation)
